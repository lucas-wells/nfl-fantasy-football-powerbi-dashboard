# NFL Fantasy Football Power BI Portfolio

A growing collection of interactive Power BI projects focused on NFL fantasy football, player performance, usage trends, predictive indicators, and sports analytics.

These dashboards were built to demonstrate practical experience with Power BI, Power Query, DAX, data modeling, dashboard design, and analytical storytelling.

## Current Projects

### [Skill Position Dashboard](Skill%20Position%20Dashboard)

A league-wide analysis of wide receivers, running backs, and tight ends across multiple NFL seasons.

Key areas include:

- Fantasy production by position
- Receiving efficiency
- Alignment tendencies
- Position-based percentile comparisons
- Individual player deep dives

### [Running Back Analytics Dashboard](RB%20Analytics%20Dashboard)

A position-specific dashboard analyzing running back production, workload, efficiency, receiving involvement, offensive line environment, and historical fantasy success thresholds.

Key areas include:

- Running back usage roles
- RB1 and RB2 hit-rate analysis
- Rushing and receiving efficiency
- Goal-line and explosive-play usage
- Run-blocking environment
- Individual player deep dives

### [Wide Receiver Analytics Dashboard](WR%20Analytics%20Dashboard)

A wide receiver-focused dashboard analyzing target earning, efficiency, alignment, quarterback accuracy, archetypes, and historical fantasy success profiles.

Key areas include:

- WR archetype analysis
- WR1, WR2, and WR3 hit rates
- Custom predictive profile filters
- Efficiency versus production
- Quarterback accuracy tiers
- Individual player-season deep dives
